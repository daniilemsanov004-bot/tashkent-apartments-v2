# Разовые/вспомогательные скрипты

Не часть основного пайплайна (`npm start` его не вызывает — тот
запускает только `src/run.js`). Это инструменты для ручного запуска
при разовых задачах:

- `setup-topics.js` — создать темы (Topics) в Telegram-супергруппах.
- `check-bot-rights.js` — проверить права бота в группах.
- `backfill-from-telegram-export.js` — разовый импорт старых
  объявлений из экспорта Telegram-чата.
- `diagnose-backlog.js` — диагностика зависших/необработанных
  объявлений в базе.
- `resend-backlog.js` — повторно отправить объявления из бэклога в
  Telegram (хранит прогресс в `resend-backlog.progress.json` рядом
  с собой, файл в .gitignore).
- `delete-agent-messages.js` — разово удалить сообщения агентов из
  Telegram-групп.
- `recheck-owners.js` — переопределить собственник/агент по уже
  сохранённым объявлениям (например, после правки правил в
  `classify.js`).
- `move-commercial-rent.js` — разовая миграция объявлений между
  категориями (коммерция ↔ аренда).
- `backfill-market-segment.js` — разово проставить market_segment
  ("новостройка"/"вторичка", см. `../marketSegment.js`) уже сохранённым
  объявлениям задним числом (по их сохранённому raw_text, без похода
  на сайты), затем пересчитать рыночную статистику. Нужен один раз
  после того, как добавили market_segment (15.08.2026) — дальше новые
  объявления размечаются сразу при скрапинге (см. run.js).

Запуск: `node src/scripts/<имя-файла>.js` из папки `scraper/`
(нужен `.env`, как и для основного скрапера).
